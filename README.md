# Palma Digital Studio / Trabajo Final JavaScript Avanzado


Sitio web de 4 páginas para una agencia de Marketing Digital

## Enlaces:

-  Repositorio en GitHub: https://github.com/Alina-Versionista-coder/trabajo_final_js
-  Web publicada (GitHub Pages): https://alina-versionista-coder.github.io/trabajo_final_js/

## Páginas:

- Inicio: presentación, servicios, reseñas de clientes y noticias cargadas desde un archivo JSON con `fetch`.
- Galería: packs de marketing con modal para ver cada imagen en grande (jQuery).
- Presupuesto: formulario con validación en vivo (expresiones regulares) y cálculo automático del total, 
  con extras y descuento según el plazo.
- Contacto: mapa con Leaflet y ruta desde la ubicación del usuario hasta la oficina.

## Tecnologías usadas:

HTML5, CSS3, JavaScript, jQuery, Leaflet y Leaflet Routing Machine.

## Estructura:

 -`index.html`: pagina de inicio
 -`views/`: galería, presupuesto y contacto
 -`css/`: estilos
 -`js/`: scripts de cada pagina
 -`data/`: noticias en formato JSON
 -`images/`: imagenes de la galeria
